## Descripción del Proyecto

**Nexora** es una plataforma web diseñada como un espacio de **microservicios entre personas**. Su objetivo es conectar de forma directa a usuarios que necesitan resolver una tarea específica con profesionales o trabajadores dispuestos a realizarla. 

El modelo funciona de manera muy sencilla: si un usuario necesita un servicio particular (por ejemplo, *"pintar la fachada de una casa"*), publica la oferta en la plataforma. Otros usuarios pueden ver este requerimiento y postularse para el trabajo. El cliente tiene la flexibilidad de evaluar los perfiles y **contratar a una o a varias personas a la vez**, dependiendo de la magnitud y las necesidades exactas de la tarea.

## Tecnologías y Herramientas

* **Framework Principal:** Next.js (App Router)
* **Librería de UI:** React
* **Estilos y Layout:** Tailwind CSS
* **Plataforma de Backend & Cloud:** Firebase (Autenticación, base de datos en tiempo real y gestión de servicios)
* **Hosting / Despliegue:** Vercel

## Características Principales

* **Publicación de Microservicios:** Interfaz simple para describir y publicar tareas o requerimientos específicos que se necesitan cubrir.
* **Postulación Dinámica:** Los trabajadores pueden explorar el feed, revisar los microservicios disponibles y aplicar a los que se ajusten a sus habilidades.
* **Contratación Flexible:** Permite al contratante seleccionar y gestionar a un único trabajador o coordinar con un equipo de múltiples personas para un mismo proyecto.
* **Talent Hub:** Panel especializado para que los proveedores de servicios gestionen sus postulaciones, estado de trabajos y presencia en la plataforma.
* **Mensajería en Tiempo Real:** Canal de comunicación interna para acordar detalles, presupuestos y plazos antes o durante la contratación.
* **Diseño Moderno y Adaptable:** Interfaz fluida optimizada para entornos web y móviles bajo una estética de modo oscuro (Dark Theme).
